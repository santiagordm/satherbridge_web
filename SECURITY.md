# Security policy

This repository holds the static website published at https://satherbridge.com. It has no server code, no forms and no user accounts.

## Reporting a vulnerability

If you find a security issue, please report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Please do not open a public issue.

Reports are reviewed by the site owner. You will get a reply as soon as possible.
